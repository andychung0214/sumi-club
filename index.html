HOUSE RULES

墨間桌規

各地大老二略有不同，這桌這樣玩。

  1. 每人 13 張，2–4 人都可開桌。未發出的牌不使用，已發出的最小牌先行，首手必須包含它。
  2. 3 最小、2 最大；相同點數比較 ♦ < ♣ < ♥ < ♠。
  3. 可出單張、對子、三條，或五張：
    順子 < 同花 < 葫蘆 < 鐵支帶一 < 同花順。
  4. 順子從 34567 至 10JQKA；2 不入順。同花先比花色，再比點數。葫蘆比三條；鐵支比四條。
  5. 必須用相同張數、更大的牌壓過前手；沒有跨張數炸彈。其他人全過，最後出牌者重新自由領出。
  6. 先清空手牌就獲勝。點選牌再按出牌；H 提示、P 過牌、Enter 出牌，Esc 取消選牌。

提示不會自動出牌。電腦只根據自己的手牌與公開資訊決策。
