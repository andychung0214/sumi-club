# 墨間牌社測試計畫

## 自動化功能

- [x] 52 張唯一牌、單張與對子花色比較。
- [x] 五種五張牌型強弱、2 不入順、相同張數限制。
- [x] 起手包含最小牌、非法出牌不變更狀態、錯誤座位不可操作。
- [x] 全員過牌回到領出者，2–3 人各 13 張。
- [x] 四種 CPU 策略在 2–4 人對局中出合法牌且結束。
- [x] 客人快照不包含其他人的手牌。
- [x] 連線碼版本、類型、長度限制；動作拒絕重複牌、超界牌與錯誤版本型別。

## 瀏覽器流程

以下是否實際通過，以 VERIFICATION.md 為準；核取方塊僅代表單元測試已執行。

- 首頁載入、WebGL canvas、無未捕捉 JavaScript 錯誤。
- 開啟桌規、Escape 關閉；提示選牌、出牌、過牌、勝利對話框、本日紀錄。
- d3 手牌分布與牌路紀錄。
- 真正四個頁面經 WebRTC 邀請／回覆連線，開局 52 張唯一牌，出牌同步。
- 客人離線時，房主與其餘客人都鎖定並提供重新邀請指引。
- 無效連線碼、取消邀請、重開局、切換模式取消舊 CPU 排程。

## 手動／行動裝置

- 390px 手機、平板與桌機無水平溢位；選牌不遮住必要操作。
- 實際 iOS Safari、Android Chrome 觸控選取與捲動。
- 洗牌兩疊交錯、依席發牌、出牌移入中央；開啟減少動態效果後略過長動畫。
- WebGL 失敗時 HTML 桌面牌仍可看見；封鎖 localStorage 不阻擋遊戲。
- 音效預設關閉，開啟後只在操作時播放。
- 不同 Wi-Fi、行動網路、公司防火牆的連線成功／失敗提示。沒有 TURN 時不得宣稱所有網路皆能連線。

## 無障礙

- Tab 可達模式、設定、手牌、出牌按鈕及關閉對話框。
- Space／Enter 操作聚焦按鈕；焦點外 H／P／Enter 快捷鍵不干擾連線碼輸入。
- 每張牌包含點數／花色文字標籤，選牌使用 aria-pressed；狀態採 aria-live。
- 當前玩家同時有「輪到出牌」文字；勝負與錯誤不只靠顏色。
- Windows NVDA、macOS VoiceOver 與 200% 字體縮放仍需人工驗證。
